# Threader

Threader is a lightweight Java-based concurrent task execution system that
demonstrates multithreading, thread-safe task scheduling, and object-oriented design.

## Features
- Parallel task execution using multiple worker threads
- Thread-safe task queue using BlockingQueue
- Clean separation of concerns
- Simple and explainable concurrency model

## Tech Stack
- Java
- Multithreading
- BlockingQueue

## How It Works
1. Tasks implement Runnable
2. Tasks are submitted to a thread-safe queue
3. Worker threads fetch and execute tasks concurrently

## How to Run
Run the Main class.
